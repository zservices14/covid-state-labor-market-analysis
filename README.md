# COVID-19 State Labor Market Analysis
Analysis of state-level unemployment and labor-force participation during the early COVID-19 labor market shock using data from the Federal Reserve Economic Data API

## Tools
- Python
- pandas
- matplotlib
- statsmodels
- FRED API

## Key Findings
- Nevada, Hawaii, Michigan, Massachusetts, and Rhode Island experienced some of the largest unemployment increases between April 2019 and April 2020.
- States with larger declines in labor-force participation generally experienced larger unemployment increases.
- A simple linear regression found a statistically significant relationship between participation changes and unemployment shocks, although labor-force participation explained only a limited share of differences across states.
- By December 2021, Alaska, Kentucky, and North Carolina had returned to their February 2020 unemployment rates in the dataset.

## Analysis
The project includes:
- API-based data collection from FRED
- Data cleaning and transformation with pandas
- State-level unemployment shock analysis
- Scatterplot and simple linear regression
- Comparison of unemployment recovery through December 2021

## Data Source

Federal Reserve Economic Data (FRED)
